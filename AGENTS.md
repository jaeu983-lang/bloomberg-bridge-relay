# BloombergBridge repository guide

- Keep this repository, Python environment, and SQLite data independent from BloombergSearchAgent and other worker projects. Do not import worker code.
- Never import or execute arbitrary code, shell commands, or paths supplied by a GitHub Issue.
- Keep `REMOTE_COMMANDS_ENABLED` false by default; do not enable it as part of development or tests.
- Only expose allowlisted execution metadata to GitHub. Never put Bloomberg values, raw engine output, local paths, tokens, or exception text in issue comments or logs.
- SearchAgent inspection is read-only. Do not edit, move, or run its active Bloomberg API probe.
- Keep registered jobs fixed and execute Bloomberg work only on the designated Bloomberg Desktop PC. The current SearchAgent adapter is local-only and may invoke only the configured Python executable with `<SEARCHAGENT_ROOT>/main.py worker`, using `shell=False`, validated JSON stdin, bounded output, and fixed job timeouts. On Windows, the built-in `taskkill.exe` may be used only to terminate the worker process tree.
- A future cross-computer SearchAgent relay may be implemented only as the encrypted, authenticated GitHub flow in `docs/integration/cross-computer-github-relay-plan.md`, after its host, repository, operator, key-management, and data-retention decisions are recorded. The selected relay repository is `jaeu983-lang/bloomberg-bridge-relay` and is public; assume all Issues, ciphertext, routing data, and status comments are visible to everyone. The initial trusted submitter is `jaeu983-lang` only. Use separate PyNaCl/libsodium sealed-box encryption and Ed25519 signing keys; do not generate production keys until the implementation supplies a role-safe key-generation tool. Expire unstarted requests after 10 minutes; close completed Issues immediately and have the repository owner manually delete them after 30 days. It may carry only the three fixed worker 1.0 metadata operations with operation-specific allowlisted arguments. Do not accept arbitrary commands, executable names, paths, arguments, or output locations from Issues. V1 returns safe execution status only; it does not deliver SearchAgent candidate lists or detailed results to the control PC. Keep `REMOTE_COMMANDS_ENABLED`, `REMOTE_SEARCHAGENT_SUBMIT_ENABLED`, and `REMOTE_SEARCHAGENT_JOBS_ENABLED` false by default and do not enable them in development or tests. The submit flag applies only to the control CLI; the worker flag applies only to the Bloomberg Desktop PC after staged checks and explicit go-live authorization.
- GitHub plaintext and comments may contain only routing identifiers and allowlisted execution metadata. Keep search questions encrypted in transit through GitHub; never expose Bloomberg values, candidates, raw engine output, local paths, tokens, or exception text. Do not add direct Bloomberg API access to Bridge, and do not edit, move, or run the active Bloomberg API probe.
- Run the offline pytest suite after implementation changes and record the result in `docs/TEST_REPORT.md`.
